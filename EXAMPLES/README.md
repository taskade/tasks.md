# Examples

Three ledgers, each a complete TASKS.md file in the format. They follow the shapes that real builds produce. Identifiers and links are replaced by placeholders, and the content is condensed so each file fits on one screen.

| File | What it shows |
|---|---|
| [01-new-build.md](./01-new-build.md) | A first build, mid-way. The map is charted, three of four clauses are settled, one is open. |
| [02-resumed-build.md](./02-resumed-build.md) | The same work after a context reset and a second session. One clause is Declared, the Archive section has appeared, and Knowledge was corrected in place. |
| [03-small-edit.md](./03-small-edit.md) | A one-turn edit on an existing build. No map was charted. Only the log moved. |

Read them in order. The third one is the most common case in practice: most turns are edits, and an edit touches only the log.
